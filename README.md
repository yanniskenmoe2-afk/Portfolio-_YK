# Portfolio — Kenmoe Dounbi Yannis

Site portfolio personnel présentant mon parcours en Systèmes et Réseaux, mes compétences techniques et mes laboratoires pratiques orientés cybersécurité.

## Technologies
- HTML5 : structure et contenu
- CSS3 : mise en page responsive, thèmes et animations
- JavaScript : menu mobile, filtre des projets, thème clair/sombre et effets d'apparition

## Utilisation locale
Ouvrir `index.html` dans un navigateur.

## Publication avec GitHub Pages
1. Créer un dépôt GitHub, par exemple `portfolio`.
2. Ajouter `index.html` et ce `README.md` à la racine.
3. Ouvrir **Settings → Pages** dans le dépôt.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`, puis enregistrer.

GitHub Pages publiera le site après le déploiement. Le lien exact sera affiché dans la section Pages des paramètres du dépôt.

## À personnaliser avant publication
- Remplacer les liens provisoires Huawei et Cisco par les URL directes de leurs dépôts.
- Vérifier les noms, descriptions et résultats de chaque projet.
- Ajouter éventuellement une bannière ou une photo professionnelle optimisée.
